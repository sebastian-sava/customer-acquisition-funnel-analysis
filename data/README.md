# Data

`marketing_performance_case.xlsx` is the synthetic workbook used for this portfolio analysis.

It was supplied as part of a recruitment analytics exercise and was described as synthetic. It should not be interpreted as real customer, employee, acquisition-cost or company-performance data.

The workbook contains six sheets:

- `README` - notes supplied with the case data
- `Leads` - one row per lead
- `Outbound` - one row per outbound contact attempt
- `Prospects` - booked visits
- `Cost` - acquisition cost by date and channel
- `Data Dictionary` - field definitions

Two caveats are particularly important for the analysis: the source documentation states that acquisition costs and contact timing were randomised, and the data stops at the booked-visit stage rather than following leads through to customers or long-term value.
